# Steen Papier Schaar

Een simpel turn-based spel waarin je het opneemt tegen de computer.

## Over het spel

Maak je keuze tussen steen papier of schaar, de computer kiest een van die opties en de winnaar wordt vervolgens bepaald. Speel meerdere rondes en hou je score bij.

## Features
1. Drie keuze knoppen: steen, papier en schaar.
2. Score overzicht bijvorbeeld (0 - 1)
3. Reset-knop voor een nieuwe ronde.

## Hoe te spelen
Klik op de knop steen, papier of schaar. De computer maakt een random keuze en de winnaar krijgt een punt.

## Regels
1. Steen verslaat schaar
2. Schaar verslaat papier
3. Papier verslaat steen
4. Gelijke keuze = gelijkspel (niemand krijgt een punt)

## Tech stack

- HTML, CSS, JavaScript (vanilla)
